## 从系统相册导入

在“视频导入”页面中，可以从系统相册选择一个或多个视频，并把它们批量导入到指定文件夹。

## 从“文件”导入

PrimePlayer 支持从系统“文件”中选择多个受支持的视频文件。独立音频文件不在导入范围内；外挂字幕需要在播放页的字幕设置中添加。

## 通过浏览器导入

当 iPhone 或 iPad 与另一台手机或电脑连接到同一个 Wi-Fi 后，可以在另一台设备的浏览器中打开 PrimePlayer 提供的本地页面，并向 PrimePlayer 上传视频。

应用还提供浏览器文件传输工具，可以在其他设备与 iPhone 或 iPad 的“文件”之间双向传输文件。

## 添加网络视频

“网络视频”区域可以填写视频地址并进行解析。项目当前列出的协议包括 HTTP/HTTPS、HLS、FTP、RTP、RTSP 和 MMS 等；具体内容能否播放取决于地址、格式和网络状态。

浏览器导入、浏览器文件传输和网络视频等部分功能在应用界面中标注为 Pro 功能。

## 整理导入内容

导入的视频会进入媒体库。PrimePlayer 的主要栏目包括媒体库、播放列表、视频导入和设置；媒体库中可以创建文件夹，播放列表可以新增、重命名、排序或删除。

## Import from Photos

The Video Import screen can select one or more videos from the system photo library and import them in batches into a chosen folder.

## Import from Files

PrimePlayer can select multiple supported video files from the system Files app. Standalone audio is not included; external subtitle files are added from subtitle settings on the player screen.

## Import through a browser

When an iPhone or iPad and another phone or computer are connected to the same Wi-Fi network, the other device can open a local page provided by PrimePlayer and upload video through its browser.

The app also includes a browser file-transfer tool for two-way transfers between another device and Files on the iPhone or iPad.

## Add network video

The Network Video section accepts and resolves video URLs. Protocols currently listed by the project include HTTP/HTTPS, HLS, FTP, RTP, RTSP, and MMS. Actual playback depends on the URL, format, and network conditions.

Browser import, browser file transfer, network video, and some related capabilities are marked as Pro features in the app interface.

## Organize imported content

Imported video appears in the media library. PrimePlayer’s main sections are Library, Playlists, Video Import, and Settings. The library can create folders, while playlists can be created, renamed, reordered, or deleted.

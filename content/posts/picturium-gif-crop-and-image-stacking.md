## 打开图片：拖入、按钮，或在 Finder 中直接打开

打开图片有几种方式：把图片直接拖进窗口；点击“打开图片”选取单张图片；点击“批量添加文件夹图片”选取一个或多个文件夹，一次性批量导入其中的图片；也可以在 Finder 里选中图片，直接用 Picturium 打开。

导入文件夹时会先给出一份预览，可以调整图片加入的顺序再确认。导入后的图片会在侧栏以缩略图列表呈现，可以按名称、修改时间、创建时间、大小或类型排序，也可以只筛选出其中的 GIF；选中任意一张缩略图即可进入查看。

## 裁剪：GIF 裁剪后动效完整保留

裁剪工具在图片上框选出保留区域，确认后可以选择覆盖原文件，或导出为新文件。

对于静态图片，这就是常规裁剪。裁剪 GIF 时，画面会跟着裁剪区域变小，但动效完整保留：帧数、每一帧的播放节奏都和原图一样，裁剪后的文件仍然是一张正常播放的动图，不会卡顿、变速，也不会变成静态图。

## 涂鸦、文字与马赛克遮挡

编辑模式下还提供画笔、文字和马赛克工具：可以绘制矩形、椭圆、直线、箭头和自由画笔，调整颜色和线条粗细；添加的文字支持切换字体和字号；马赛克工具在需要遮挡的区域涂抹即可生成像素化效果，用于遮挡人脸、证件号码等敏感信息。所有编辑元素都可以单独选中、移动、旋转和缩放，支持撤销和重做。

## 叠图合成：图片和 GIF 叠加，动图可以叠动图

“叠图”是编辑模式中的另一种模式，用来把多张素材叠加到当前图片上。添加叠加素材有三种方式：从文件夹缩略图侧栏把一张图片或 GIF 拖到画布上；直接把图片或 GIF 从 Finder 拖入画布；或点击“添加图片”按钮一次选取多张图片。无论用哪种方式加入，素材都会作为新的一层叠加上去，每一层都可以单独拖动位置、旋转角度和缩放大小。

叠图支持动图叠动图。如果底图或叠加的素材里有 GIF，合成后得到的仍然是一张会动的图：底图和每一张叠加的 GIF 会各自按自己原本的节奏播放，而不是把某一帧画面固定贴在另一张动图上。

只要结果里含有动画，保存或导出时就需要把格式选为 GIF，否则动效会丢失。

## 保存与导出

裁剪和叠图完成后，都可以选择“保存”覆盖原文件，或“导出”为新文件、保留原图不变。保存会直接覆盖原文件内容，通常无法撤销；处理重要或唯一的图片前，建议先用“导出”生成一份副本。

## Opening images: drag in, use a button, or open from Finder

There are a few ways to bring images in: drag an image straight into the window; click "Open Image" to pick a single file; click "Add Folder Images" to pick one or more folders and import everything inside them at once; or select an image in Finder and open it directly with Picturium.

Importing a folder shows a preview first, where you can adjust the order images will be added in before confirming. Imported images then appear in the sidebar as a list of thumbnails, sortable by name, modification date, creation date, size, or kind, and filterable down to just GIFs. Selecting any thumbnail opens it in the viewer.

## Cropping: GIFs keep their motion after a crop

The crop tool lets you draw the area to keep, then either overwrite the original file or export a new one.

For a still image, that's a normal crop. For a GIF, the picture gets smaller but the motion stays whole: the same number of frames, played at the same pace as the source. The cropped file is still a normally playing animation — no stutter, no change in speed, and it never collapses into a still image.

## Drawing, text, and mosaic redaction

Editing mode also includes pen, text, and mosaic tools: draw rectangles, ellipses, lines, arrows, and freehand strokes with adjustable color and stroke width; add text with a choice of font and size; and paint over an area with the mosaic tool to pixelate it, for redacting faces, ID numbers, and other sensitive details. Every element on the canvas can be selected, moved, rotated, and resized on its own, with undo and redo throughout.

## Stacking: composite images and GIFs, including GIF-on-GIF

Stacking is a separate mode within editing, used to layer additional media on top of the current image. Layers can be added three ways: drag an image or GIF from the folder thumbnail sidebar onto the canvas; drag one in directly from Finder; or click "Add Image" to pick multiple files at once. However it's added, the media becomes a new layer, and each layer can then be dragged, rotated, and resized independently.

Stacking supports GIF-on-GIF. If the base image or any of the stacked layers is a GIF, the result is still an animated file: the base and every stacked GIF keep playing at their own original pace, rather than one animation being frozen onto a single frame of another.

Whenever the result includes animation, save it or export it as a GIF — any other format would lose the motion.

## Saving and exporting

After cropping or stacking, you can either “Save” to overwrite the original file, or “Export” to write a new file and leave the original untouched. Save overwrites the original in place and usually can't be undone, so for an important or irreplaceable image, exporting a copy first is the safer route.
